# Sistema de Estudos em C#

Repositório com os sistemas que desenvolvi durante meus estudos de C# e .NET

## Sistemas

- **Funcionários**: CRUD com validações, busca e filtro
- **Livros**: CRUD com controle de empréstimo/devolução
- **Banco**: Conta corrente/poupança, saque, depósito, transferência
- **Pedidos (Console)**: CRUD com EF Core + SQL Server + Menu interativo
- **Pedidos (API)**: Web API com Swagger + EF Core + SQL Server

## Tecnologias

- C# / .NET
- Programação Orientada a Objetos
- LINQ
- Git / GitHub
